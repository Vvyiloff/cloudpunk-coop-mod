Cloudpunk Co-op — тестовая сборка от 14 октября 2026 года
Протокол 18. Для Windows 64-bit.

УСТАНОВКА КОПИРОВАНИЕМ

1. У тебя должна быть установлена собственная Cloudpunk. Закрой игру.
2. Открой папку «Скопировать в папку игры» из этого комплекта.
3. Скопируй ВСЁ ЕЁ СОДЕРЖИМОЕ в каталог, где лежит Cloudpunk.exe.
   В результате winhttp.dll и doorstop_config.ini должны лежать рядом
   с Cloudpunk.exe, а не внутри дополнительной вложенной папки.
4. Запусти Cloudpunk обычным способом. При первом запуске загрузчик
   создаёт interop-файлы: запуск может занять дольше обычного.

Загрузчик BepInEx, встроенный .NET runtime, библиотеки для генерации
interop и две DLL мода уже включены. SDK и отдельная установка
загрузчика для игры не нужны. Базовые библиотеки Unity включены;
их скачивание при первом запуске отключено в настройках комплекта.

Если у тебя уже установлен BepInEx или другие моды, перед заменой
сохрани копию BepInEx, dotnet, winhttp.dll и doorstop_config.ini.
Этот полный комплект содержит конкретную проверенную версию загрузчика.
Также сохрани резервную копию своих сохранений:
%USERPROFILE%\AppData\LocalLow\ION LANDS\Cloudpunk

КАК СОЕДИНИТЬСЯ

У обоих игроков должна быть одинаковая сборка этого мода.
Хост: F9 → Host → Start Host. Порт по умолчанию: TCP 27050.
Друг: F9 → Join → IPv4 хоста и тот же порт → Connect.
В главном меню также есть кнопка Host / Join.

Адрес 127.0.0.1 подходит только для двух окон на одном компьютере.
Для разных компьютеров используйте доступный LAN/VPN-адрес хоста.
Через обычный интернет нужен доступный внешний IPv4 и настройка
TCP 27050 на стороне хоста. Автоматического обхода NAT здесь нет.
При запросе брандмауэра разреши доступ для выбранной сети.

УПРАВЛЕНИЕ

F9       — подключение / отключение.
E        — посадка / выход, парковка по игровому контексту.
Shift+E  — посадка в машину напарника.
F8       — запрос и подтверждение обмена местами.

В стандартных настройках Role = Off, диагностика и автопилот выключены.
Соединение создаётся после выбора Host / Join, а не сразу при запуске игры.

После игры гостем перезапусти Cloudpunk для обычной одиночной игры:
защита одиночных сохранений гостя остаётся активной до перезапуска.
Данные Player 2 сохраняются отдельно на компьютере хоста в
BepInEx\config\CloudpunkCoop. Этот каталог нужно сохранять при обновлениях.

ВАЖНО О СОСТОЯНИИ ВЕРСИИ

Это текущая тестовая версия, а не законченная полная бета.
Две машины, мир, анимации и базовые диалоги уже реализованы.
Расход EnergyDrink, защита от повторных запросов, пауза,
переподключение и восстановление эффекта после перезапуска проверены.
Полная синхронизация квестов, торговли и сюжетных действий игроков
в разных регионах ещё не завершена. Проверяйте на резервных сохранениях.

Проверенная установка: Cloudpunk GOG, Unity 2018.4.29f1
(версия файлов 2018.4.29.5295330), BepInEx 6.0.0-be.682
с генератором Il2CppInterop 1.4.6. Совместимость с другими версиями
игры и другими загрузчиками отдельно не подтверждена.
Комплект проверен в двух окнах на одном ПК; запуск на ПК друга
и соединение через интернет пока не проверялись.

КАК УДАЛИТЬ

Закрой игру. Удали две DLL CloudpunkCoop из BepInEx\plugins.
Если до установки загрузчика не было, восстанови свою копию каталога
игры или убери добавленные этим комплектом файлы загрузчика.
Если BepInEx уже был — восстанови его резервную копию.
Не удаляй другие моды, сохранения и данные Player 2.

Для сообщения об ошибке приложи BepInEx\LogOutput.log,
версии игры/мода и короткие действия, после которых появилась проблема.
Перед отправкой просмотри лог: не пересылай личные данные без необходимости.

Контрольные суммы файлов находятся в CHECKSUMS.sha256.
Сведения о компонентах — в THIRD-PARTY-NOTICES.txt.
