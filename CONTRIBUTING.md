# Участие в разработке

1. Создайте форк репозитория в своём аккаунте GitHub и клонируйте его.
2. Создайте отдельную ветку: `git switch -c fix/short-description`.
3. Внесите изменения и выполните тесты из README. Для изменений игровой интеграции также соберите плагин на собственной установке и проверьте затронутое поведение в игре.
4. Сделайте коммит, отправьте ветку в свой форк и откройте Pull Request в `Vvyiloff/cloudpunk-coop-mod:main`.

В описании укажите проблему, итоговое поведение, выполненные проверки и известные ограничения. Не объявляйте проверку на одном компьютере доказательством работы на двух компьютерах или через Интернет.

Сохраняйте существующие изменения и состояние игры. Не включайте DLL игры, дампы, interop, логи, сохранения, личные адреса или секреты. Готовые сборки распространяются через Releases; `main` предназначен для исходников.

Для изменения формата сетевых сообщений учитывайте совместимость протокола и обновляйте соответствующие тесты. Не смешивайте исправление одной подсистемы с несвязанными изменениями.

Скачивание кода и предложение изменений доступны через публичный репозиторий. Отдельная лицензия проекта пока не выбрана; это не означает неограниченного разрешения на любое дальнейшее распространение. Лицензии сторонних компонентов находятся в установочном архиве и сохраняются вместе с ним.
