The supplied BepInEx/unity-libs directory contains the60 managed Unity API
base-library files used by the existing tested IL2CPP generator, for Unity2018.4.29.
The loader normally obtains these from:
https://unity.bepinex.dev/libraries/2018.4.29.zip
This package uses the existing matching library snapshot and sets
IL2CPP.UnityBaseLibrariesSource to an empty value to avoid downloading it again.
These are generator dependencies, not Cloudpunk's executable or gameplay assemblies.
They are third-party Unity components; this package assigns them no new license.

The mod DLLs are a separate current CloudpunkCoop test build, protocol18.
The complete matching working-source snapshot is supplied separately alongside
this friend package. Existing component licenses retain their respective scope;
this notice does not assign a new license to the user's mod.

Cloudpunk.exe, GameAssembly.dll, Assembly-CSharp.dll, UnityPlayer.dll,
Cloudpunk_Data, generated interop, personal logs/configuration and saves are
not included. The recipient must have their own compatible game installation.
