# Cloudpunk Co-op — файлы мода

Отдельный репозиторий установочного комплекта от 14 октября 2026 года, протокол 18. Это экспериментальная тестовая сборка. Полная бета ещё не завершена; совместная игра на двух отдельных компьютерах требует проверки.

## Установка

1. Закройте игру. Если моды уже установлены, сохраните резервную копию их файлов.
2. Скопируйте **содержимое** папки `Скопировать в папку игры` в каталог с `Cloudpunk.exe`.
3. Прочитайте `НАЧАТЬ ЗДЕСЬ.txt`: там описаны подключение, управление и ограничения.

Загрузчик, необходимые библиотеки и DLL мода включены. При первом запуске загрузчик создаёт служебные файлы. Лицензии и исходники компонентов загрузчика находятся в комплекте; подробности — в `THIRD-PARTY-NOTICES.txt`.

## Проверка файлов

Из корня репозитория в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Verify-Package.ps1
```

Ожидаемый результат: `PASS: 301 package files match SHA256.` Манифест проверяет исходный установочный комплект; README и настройки Git добавлены отдельно. Git сохраняет точные байты файлов, включая переводы строк.

## Хранение и обновления в Git

Основная ветка — `main`. Первая версия отмечена тегом `test-2026-10-14-protocol18`.

Для новой сборки замените файлы комплекта и его `CHECKSUMS.sha256` файлами из нового проверенного пакета. Если файлы были исключены из нового пакета, удалите соответствующие старые файлы из репозитория. Выполните проверку выше, затем:

```powershell
git status --short
git add --all
git diff --cached --stat
git commit -m "chore(mod): update verified distribution"
```

Не копируйте в репозиторий игровой каталог целиком: сохранения, личные настройки, логи и автоматически созданные библиотеки не входят в установочный комплект. Включённые стандартные конфиги предназначены для распространения; личные адреса и профили храните в установленной игре.
