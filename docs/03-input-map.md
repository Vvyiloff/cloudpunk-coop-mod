## Why this matters

Iteration 4 injects a remote player's control by feeding these named actions from a
virtual InControl device on the car host. The eight driving actions are all
`PlayerAction` entries on one `PlayerActionSet`, reachable by name through
`PlayerActionSet.actionsByName`, so no vehicle code has to be patched.
